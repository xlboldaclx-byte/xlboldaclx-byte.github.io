Privacy policy

This policy explains the private Empire Command Bridge application used by the owner of Circle Bar V Workshop, and this public information website.

1. Operator and purpose

The application is operated by the Workshop’s owner, identified on GitHub as xlboldaclx-byte. It retrieves owner-authorized YouTube information to display channel performance, prepare private reports and support owner-requested content planning. It is not a public account-connection service.

2. Google data accessed

The connector uses YouTube Data API v3 and YouTube Analytics API. It reads the selected channel’s ID, title and handle, plus aggregate views, estimated watch minutes and subscribers gained for a selected reporting period.

The requested scopes are https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/yt-analytics.readonly. The current connector does not retrieve private messages, viewer identities or monetary reports, and does not request video upload, modification or deletion permissions.

3. Authorization and credentials

The owner selects a Google Desktop OAuth client file locally, signs in directly with Google in a system browser, grants the requested permissions and confirms the channel in the application. The application does not ask for or store the owner’s Google password.

OAuth access tokens, a refresh token and client details are stored on the owner’s Windows computer using CurrentUser DPAPI encryption. A refresh token permits renewal of access until Google expires it or the owner revokes it. Credentials are not intentionally included in reports or this website.

4. Use, processing and sharing

Retrieved information can appear in the owner’s desktop interface, locally saved reports and execution traces. Configured owner-only Telegram briefings may include report results and are processed by Telegram when delivered.

When the owner requests AI-assisted analysis, selected channel information, metrics or report excerpts can be sent as context to the configured AI provider, including OpenAI or DeepSeek depending on the selected route. The provider processes that information under its applicable service terms and privacy settings. The operator must select and configure providers consistently with the permissions granted by the owner and Google’s applicable data-use requirements.

Google data is used for the owner-facing reporting and analysis described here. Selling it, using it for targeted advertising, and using it to train general-purpose AI models are not approved purposes of this integration. The application does not implement an AI model-training pipeline.

Google data handling must follow the Google API Services User Data Policy, including its applicable Limited Use requirements. Any additional sharing or changed purpose requires updated disclosure and appropriate owner consent before that use.

5. Storage, retention and security

Reports, conversation records and traces are stored on systems controlled by the owner and can be included in the owner’s backups or configured monitoring. Reports are not claimed to have the same DPAPI protection as credentials. Access depends on the owner’s device, account and backup security controls.

The application has no fixed automatic deletion period for these local records. They remain until the owner removes them; backups and external service records may remain under their respective retention settings. The public website is not used to store channel analytics or OAuth credentials.

6. Owner controls and deletion

The owner can stop future API access by revoking the application in Google Account connections and disabling the local analytics reader. Revoking access does not automatically remove previously saved reports, traces or backups.

The owner controls the local application’s credential store and saved files and can remove those records through the relevant local administration and review process. Data retained by Google, Telegram or an AI provider is managed through that service’s account controls and policies. Do not post credentials or private reports in public support requests.

7. This website

This is a static information site. Its files contain no sign-in form, analytics script, advertising tracker or application cookie code. If hosted on GitHub Pages, GitHub processes hosting and security information such as visitor IP addresses under the GitHub Privacy Statement. Following links to other services is subject to their policies.

8. Contact and updates

For application or privacy questions, use the operator’s GitHub profile to locate a project contact channel. Because the app is privately operated for its owner, requests about connected data must be handled by that owner. Ask for a private contact method before sharing sensitive information.

This policy will be updated when data practices change. A new use of Google data requires appropriate disclosure and consent before the change is applied.

Related policies: Google Privacy Policy, OpenAI Privacy Policy, DeepSeek Privacy Policy and Telegram Privacy Policy.
